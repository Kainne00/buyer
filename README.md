# MQ Point Merchant Buyer

NOTE:
THIS IS VIBE CODED THROUGH AI.
It has worked in my tests, but things might not work correctly -- if there's a problem, message me, submit a pr, etc, and a fix will be.. uh.. fixed.

An ImGui Lua script for MacroQuest on EQ Might server (EMU). Snaps to the right of the merchant window for quick multi-purchases. Similar to how the "Vendor" lua (credit: Derple) operates.

## Supported Vendors & Items
* **Walter**: Token of Legendary Might, Token of Epic Might
* **Cloe**: Token of Legendary Might
* **Wolfie**: Token of Epic Might
* **Adrienne**: Grimoire of Otherworldly Experience, Grimoire of Boundless Experience, Voucher for 600 Tokens of Might

## Usage
1- Run `/lua run buyer` in your mq console or mq chat wnd.
2. Open any supported point merchant window.
3. Use the docked sidecar window to buy your shit.
4. I'm an idiot, please report bugs here!
